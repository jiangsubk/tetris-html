# Tetris HTML

纯 HTML/CSS/JS 俄罗斯方块游戏，浏览器直接打开即可游玩。

## 玩

直接用浏览器打开 `index.html` 即可，无需任何依赖。

或者在线玩：https://jiangsubk.github.io/tetris-html/

## 操作

| 按键 | 功能 |
|------|------|
| ← → | 左右移动 |
| ↑ | 旋转 |
| ↓ | 加速下落 |
| 空格 | 直接落底 |
| C | 暂存 (Hold) |
| P | 暂停 |
| R | 重新开始 |

手机端也支持触屏按钮操作。

## 特性

- 7-bag 公平随机算法
- 影子方块
- Hold 暂存
- 墙踢 (Wall Kick)
- 自适应计分 + 等级加速
- 触屏支持
- 响应式布局
